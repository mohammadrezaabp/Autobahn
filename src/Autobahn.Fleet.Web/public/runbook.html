Host troubleshooting

An unreachable agent means Autobahn cannot read that host. Check that the agent service is running, its network address is reachable, and its token matches the fleet settings.

Missing GPU readings usually mean the NVIDIA tools or driver are unavailable. Check the driver and container runtime before applying a deployment.

Review disk space before downloading a model. Autobahn reserves free space and refuses deletion while a managed model or a container mount is in use.

A failed deployment may have completed some host operations. Review the host and activity log, then prepare a new change using the desired specification.
