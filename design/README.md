# Autobahn interface

Both consoles use the shared workspace stylesheet and theme module in this directory.

- Horizontal text navigation replaces the sidebar layout.
- Warm ivory surfaces, forest ink and burnt-orange accents define the palette.
- A road-inspired monogram and lowercase wordmark establish the product identity.
- Large editorial headings, serif emphasis and restrained operational panels create the page hierarchy.
- The gateway includes a split sign-in page and a three-step first-request setup flow.
- Fleet pages have distinct headings, a continuous resource summary and redesigned host cards.
- Light is the default appearance. Dark and system modes share one preference across the consoles.
- Narrow layouts preserve navigation, actions and readable forms. Reduced-motion preferences are respected.

Component behavior stays in the relevant frontend project. The Docker frontend stage copies this directory before bundling either console.
